# commission-tracker
A python command line tracker I created to log orders I received through my artwork business.

## What my project does:
- adds orders [customer name and details of their order]
- allows the user to view all orders and tracks how many are delivered 
- users can mark orders as delivered to keep on top of their workload.
- delete orders
- saves orders to a file

## How to run it:
1. install python 3
2. download "commission_tracker.py"
3. run the file in a terminal

## What I learned:
- how to store orders in a list and using a loop ('for i in range(len(orders))') to display the orders with numbers
- saving orders to a text file
- using try/except commands to ensure wrong input doesn't crash the programme, rather sends a message to the user.
